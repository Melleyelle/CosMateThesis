# ระบบค่าเช่าและค่ามัดจำชุด

> **สถานะ:** ลงระบบแล้วใน SQL Step 21 ([sql/cosmate_step21_tier_deposits.sql](sql/cosmate_step21_tier_deposits.sql))
> ดูส่วน [การลงระบบจริง](#การลงระบบจริง-cosmate) ท้ายเอกสารสำหรับสิ่งที่ปรับให้เข้ากับโครงสร้างของ CosMate

## 1. ภาพรวม

- ค่าเช่าคิดจาก **ต้นทุนชุด** และแบ่งเป็น 5 เทียร์
- ชุดใหม่ที่ยังไม่คืนทุนจะใช้ **มัดจำพิเศษ 4 รอบแรก** โดยลดลงทีละขั้น
- ตั้งแต่รอบที่ 5 เป็นต้นไป ใช้ **มัดจำปกติ** ของเทียร์
- เป้าหมาย: ถ้าลูกค้าไม่คืนชุดในรอบใดก็ตาม ค่าเช่า + มัดจำที่ยึดไว้ต้องครอบคลุมต้นทุนที่ยังไม่คืน

## 2. ตารางเทียร์

| เทียร์ | ต้นทุนชุด (บาท) | ค่าเช่า (บาท) | มัดจำรอบ 1 | รอบ 2 | รอบ 3 | รอบ 4 | รอบ 5 ขึ้นไป (ปกติ) |
|---|---|---|---|---|---|---|---|
| 1 | 600 – 850 | 250 – 350 | 500 | 400 | 300 | 200 | 100 |
| 2 | 851 – 1,250 | 400 – 500 | 750 | 600 | 450 | 300 | 150 |
| 3 | 1,251 – 1,600 | 550 – 650 | 950 | 750 | 550 | 350 | 200 |
| 4 | 1,601 – 2,000 | 700 – 800 | 1,200 | 950 | 700 | 450 | 250 |
| 5 | 2,001 – 2,500 | 850 – 1,000 | 1,500 | 1,200 | 900 | 600 | 300 |

## 3. วิธีคิดราคา

### 3.1 ค่าเช่า

1. หาเทียร์จาก **ต้นทุนชุด**
2. ค่าเช่า = 40% ของต้นทุน ปัดขึ้นเป็นหลัก 50
3. ถ้าได้ต่ำกว่าค่าเช่าขั้นต่ำของเทียร์ ให้ใช้ค่าเช่าขั้นต่ำของเทียร์

| ต้นทุน | 40% | ปัดขึ้นหลัก 50 | เทียร์ | ค่าเช่าสุดท้าย |
|---|---|---|---|---|
| 600 | 240 | 250 | 1 | 250 |
| 1,000 | 400 | 400 | 2 | 400 |
| 1,700 | 680 | 700 | 4 | 700 |
| 1,650 | 660 | 700 | 4 | 700 |
| 2,500 | 1,000 | 1,000 | 5 | 1,000 |

> ด้วยสูตรนี้ ค่าเช่าทุกชุด ≥ 40% ของต้นทุน ทุกชุดจึงคืนทุนจริงภายใน 3 รอบ

### 3.2 มัดจำปกติ

ประมาณ 1 ใน 3 ของค่าเช่ากลางของเทียร์ (ใช้หลักเดียวกับตารางเดิมของร้าน)

### 3.3 มัดจำชุดใหม่ (รอบ 1–4)

- **รอบ 1** = ต้นทุนสูงสุดของเทียร์ − ค่าเช่าสูงสุดของเทียร์
  - เช่น เทียร์ 1: 850 − 350 = 500
  - คิดจากชุดที่ทุนสูงสุดในเทียร์ ทุกชุดในเทียร์จึงคุ้มทุนแน่นอน
- **รอบ 2–4** = ลดลงทีละขั้นเท่า ๆ กัน (ปัด**ลง**หลัก 50) จนถึงมัดจำปกติในรอบ 5
  - รอบเหล่านี้เก็บมากกว่าที่ต้องใช้เพื่อคุ้มทุนเล็กน้อย จึงทำหน้าที่เป็นเงินเผื่อค่าซ่อม/ค่าเสียหายด้วย

## 4. Logic ในระบบ

### 4.1 ข้อมูลที่ต้องเก็บ

**ตาราง `tiers`**

| field | ความหมาย |
|---|---|
| `tier_id` | 1–5 |
| `cost_min`, `cost_max` | ช่วงต้นทุน |
| `rent_min`, `rent_max` | ช่วงค่าเช่า |
| `deposit_new` | array มัดจำรอบ 1–4 เช่น `[500, 400, 300, 200]` |
| `deposit_normal` | มัดจำปกติ |

**ตาราง `dresses`**

| field | ความหมาย |
|---|---|
| `cost_price` | ต้นทุนชุด (แอดมินกรอก) |
| `tier_id` | คำนวณจาก `cost_price` |
| `rental_price` | คำนวณอัตโนมัติ (แอดมินแก้ได้) |
| `completed_rentals` | จำนวนครั้งที่ถูกคืนสำเร็จ |
| `total_rental_income` | ค่าเช่าสะสมจากรอบที่คืนสำเร็จ |
| `deposit_override` | มัดจำที่แอดมินกำหนดเอง (nullable) |

**ตาราง `bookings`**

| field | ความหมาย |
|---|---|
| `rental_price_snapshot` | ค่าเช่า ณ ตอนจอง |
| `deposit_snapshot` | มัดจำ ณ ตอนจอง (ล็อกไว้ ไม่เปลี่ยนตาม) |
| `round_no` | รอบที่ของชุด ณ ตอนจอง |
| `status` | booked / picked_up / returned / cancelled / not_returned |

### 4.2 คำนวณค่าเช่าตอนเพิ่ม/แก้ไขชุด

```
function calcRentalPrice(cost):
    tier = findTierByCost(cost)
    if tier is null:
        warn("ต้นทุนอยู่นอกช่วง 600–2,500 ให้แอดมินกำหนดราคาเอง")
        return null

    price = ceil(cost * 0.40 / 50) * 50
    price = max(price, tier.rent_min)
    price = min(price, tier.rent_max)
    return price
```

### 4.3 คำนวณมัดจำตอนจอง

```
function calcDeposit(dress):
    if dress.deposit_override is not null:
        return dress.deposit_override

    tier  = dress.tier
    round = dress.completed_rentals + 1

    if round <= 4:
        return tier.deposit_new[round - 1]
    else:
        return tier.deposit_normal
```

ตอนสร้างใบจอง ให้บันทึก `deposit_snapshot`, `rental_price_snapshot` และ `round_no` ทันที

### 4.4 เมื่อคืนชุด

```
on booking status → returned (ตรวจสภาพแล้ว):
    dress.completed_rentals   += 1
    dress.total_rental_income += booking.rental_price_snapshot
```

- นับรอบ **เฉพาะการคืนสำเร็จ** เท่านั้น
- `cancelled` และ `not_returned` ไม่นับรอบ

### 4.5 สถานะ "คืนทุนแล้ว" (ใช้แสดงผล/รายงาน)

```
is_paid_off = dress.total_rental_income >= dress.cost_price
```

## 5. กรณีพิเศษ

| กรณี | การจัดการ |
|---|---|
| ต้นทุนต่ำกว่า 600 หรือเกิน 2,500 | ไม่จัดเทียร์อัตโนมัติ แจ้งเตือนให้แอดมินกำหนดราคาเอง |
| แอดมินแก้ค่าเช่าเอง | แจ้งเตือนถ้าค่าเช่าต่ำกว่า 40% ของต้นทุน (เทียร์ยังอิงต้นทุน — ดูการลงระบบจริง) |
| มีการจองล่วงหน้าหลายรายการ | มัดจำแต่ละใบจองใช้ค่า ณ ตอนจอง ไม่ย้อนแก้ภายหลัง |
| ลูกค้าไม่คืนชุด | ยึดมัดจำ, เปลี่ยนสถานะชุดเป็นสูญหาย, ไม่นับรอบ |
| ชุดเสียหายระหว่างเช่า | หักค่าซ่อมจากมัดจำ, ยังนับเป็นรอบที่คืนสำเร็จ |

## 6. ตัวอย่างการทำงาน

ชุดต้นทุน 1,700 บาท → เทียร์ 4 → ค่าเช่า 700

| รอบ | มัดจำ | ค่าเช่าสะสมหลังคืน | ถ้าไม่คืนชุด ร้านได้ (ค่าเช่า + มัดจำ) | ทุนคงเหลือก่อนรอบนี้ |
|---|---|---|---|---|
| 1 | 1,200 | 700 | 1,900 | 1,700 |
| 2 | 950 | 1,400 | 1,650 | 1,000 |
| 3 | 700 | 2,100 (คืนทุนแล้ว) | 1,400 | 300 |
| 4 | 450 | 2,800 | 1,150 | 0 |
| 5+ | 250 | – | – | 0 |

## การลงระบบจริง (CosMate)

ตรวจตัวเลขแล้ว: ทุกต้นทุน 600–2,500 บาท (ทีละ 1 บาท) ค่าเช่า + มัดจำของทุกรอบครอบคลุมทุนที่ยังไม่คืน และคืนทุนภายใน 3 รอบ

| สเปก | CosMate |
|---|---|
| ตาราง `tiers` | `rental_tiers` |
| `dresses` (1 ชุด = 1 ชิ้น) | ต้นทุน/มัดจำกำหนดเองอยู่ที่ `products` (ทุกไซส์ทุกตัวใช้ต้นทุนเดียวกัน) · **รอบนับแยกรายตัวจริง** (`product_items`) ตัวที่ซื้อเพิ่มทีหลังเริ่มรอบ 1 ใหม่ |
| `completed_rentals`, `total_rental_income` | ไม่เก็บเป็นตัวนับ นับสดจากรายการที่ออเดอร์ "เสร็จสิ้น" (`unit_completed_rentals`, `unit_rental_income`) — ไม่เพี้ยน และนับออเดอร์เก่าย้อนหลังให้เอง |
| `not_returned` ไม่นับรอบ | รายการที่มีการหัก "สูญหาย" (`order_deductions.type = 'lost'`) ไม่นับ |
| `rental_price_snapshot`, `deposit_snapshot`, `round_no` | `order_items.rental_price`, `deposit_amount`, `round_no` |
| `rental_price` ของชุด | `product_variants.package_price` (รายไซส์) ฟอร์มเสนอค่าเช่าจากต้นทุนและกดใช้กับทุกไซส์ได้ |
| แอดมินแก้ค่าเช่าเอง → คำนวณเทียร์ใหม่ | **เทียร์อิงต้นทุนเสมอ** เพราะมัดจำออกแบบมาให้คุ้มทุน ซึ่งขึ้นกับต้นทุน แก้ค่าเช่าเองได้ แต่เตือนถ้าต่ำกว่า 40% ของต้นทุน |
| ไม่มีต้นทุน / นอกช่วง | ใช้มัดจำที่กรอกเองรายไซส์แบบเดิม (ชุดเก่าที่ยังไม่กรอกต้นทุนทำงานเหมือนเดิม) |

**เพิ่มจากสเปก**

- **ไซส์หนึ่งมีหลายตัว** — ตอนจองระบบเลือกตัวที่มัดจำถูกที่สุดก่อน (ตัวที่ผ่านมาหลายรอบ) ลูกค้าเห็นมัดจำของตัวที่จะได้จริงเมื่อเลือกวันแล้ว ก่อนเลือกวันเห็นเป็นช่วง เช่น ฿250–฿1,200
- **เช่าแยกชิ้น** — มัดจำ = มัดจำทั้งชุดของตัวนั้น × (ราคาชิ้นรวม ÷ ราคาทั้งชุดของไซส์) ปัดขึ้นหลัก 50 ไม่เกินมัดจำทั้งชุด (แทนตารางมัดจำตามยอดค่าเช่าแบบเดิม)
- **รองเท้าที่มากับชุด** — รายการรองเท้าราคา 0 มัดจำ 0 เหมือนเดิม รอบของรองเท้าคู่นั้นยังนับ แต่ค่าเช่าสะสมไม่เพิ่ม (ค่าเช่ารวมอยู่ในรายการชุด)
- **ยกเลิกช้ากว่า 3 วันก่อนใช้งาน** — ยังยึดมัดจำเต็มตามนโยบายเดิม (รวมมัดจำรอบแรกที่สูง)
